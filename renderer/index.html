Telegram accounts

Each account has its own API keys, session and proxy.

Create a new Telegram account

Rents a number on TextVerified, signs up on your VMOS cloud phone, then Camoufox creates this account's own API keys through a proxy. Takes a few minutes.

    Add a Telegram account

    Step 1 of 2 — this account's own phone number and its own Telethon keys. Get the API ID and hash by logging into my.telegram.org with this account → API development tools.

    Step 2 of 2 — Telegram sent a code to the Telegram app on your phone (not SMS).

    Proxies

    Add proxies once. Accounts and Camoufox use them automatically.

    Add proxies

    One per line. Formats: host:port, host:port:user:pass, http://user:pass@host:port, socks5://user:pass@host:port. Residential proxies work best. Each account can use its own proxy for Telegram and for Camoufox.

    Camoufox

    Open-source stealth browser, built in. Creates each account's API keys on my.telegram.org through its proxy.
